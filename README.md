# Паркинг на Базовской

Страница инициативной группы жителей ЖК «На Базовской» (Москва, Западное Дегунино) о нехватке парковочных мест и предложении построить капитальный паркинг под управлением Московского паркинга.

Сайт: https://georgy-fomk1n.github.io/parking-zhkb/

Карта участка построена на данных © участники OpenStreetMap (лицензия ODbL), библиотека Leaflet (BSD-2-Clause).

## Обновление итогов опроса

Скрипт `tools/survey.py` пересчитывает итоги по выгрузке из Яндекс Форм:

```
python3 tools/survey.py ~/Downloads/выгрузка.csv index.html
```

Он печатает цифры для карточек и FAQ и пересобирает таблицу «Ответы по корпусам» в `index.html`. Карточки, FAQ и даты правятся вручную по напечатанным цифрам. Методика описана в начале скрипта. CSV-выгрузки в репозиторий не коммитим.
